# AWS S3 Static Website Hosting

This project demonstrates how to host a static website using Amazon S3.  
It includes the website file, documentation, and a workflow diagram showing the setup.

---

## Workflow Diagram

![Diagram](https://github.com/md-mota/aws-S3-SimpleWebsite/blob/main/workflow-diagram.png)

---

## What This Project Covers

- Creating an S3 bucket  
- Uploading static website files  
- Enabling static website hosting  
- Setting the index document  
- Configuring bucket permissions for public access  
- Accessing the S3 website endpoint  

---

## Skills Demonstrated

- AWS S3 fundamentals  
- Static website hosting  
- Bucket policies & public access  
- Cloud documentation and diagrams
